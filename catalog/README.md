# Community ruleset catalog

This directory is the source of truth for the AGF community marketplace catalog.

- Catalog data: `community-catalog.json`
- Schema: `community-catalog.schema.json`
- Design notes: `/Users/cvsteenbergen/Code/agf/docs/RULESET_MARKETPLACE.md`

## ID convention

Use reverse-DNS style IDs to avoid collisions:

- `dev.company.product.topic`

The `id` maps directly to `publicBundleId` when publishing with:

- `POST /api/v1/customers/:customerId/bundles`

## Author workflow

1. Add or update rule files under `/Users/cvsteenbergen/Code/agf/agf-sp1/rules/**`.
2. Validate each file:
   - `cargo run --manifest-path /Users/cvsteenbergen/Code/agf/agf-sp1/script/Cargo.toml --bin arsl-validate -- --file /Users/cvsteenbergen/Code/agf/agf-sp1/rules/<path>.arsl.toml`
3. Compute digest using the same algorithm as control-plane publish:
   - `node /Users/cvsteenbergen/Code/agf/scripts/marketplace-compute-digest.mjs --rule-file rules/<path>.arsl.toml`
4. Add/update catalog entry with `id`, `version`, `digest`, `ruleFiles`, and metadata.
5. Open a pull request.
